# Hindibook (हिंदीबुक)

A Hindi audiobook/story reader for Android with Text-to-Speech, offline caching, and customizable reading experience.

## Features
- Server-driven story catalog with categories
- Offline caching with automatic cache management
- Save stories to SD card
- Hindi Text-to-Speech with adjustable speed (7 levels)
- 3 Hindi fonts, 8 background colors, text size 16-24sp
- Pro subscription model for premium content
- In-app update checker

## Build
```
./gradlew assembleDebug
```
Min SDK 14, Target SDK 21.
